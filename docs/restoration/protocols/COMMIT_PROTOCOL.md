# Commit Protocol

## Identity

All new commits:

`Rishi Garg <rishiguruji2901@gmail.com>`

## Verification

Before commit:

```bash
git config user.name "Rishi Garg"
git config user.email "rishiguruji2901@gmail.com"

git config user.name
git config user.email
```

After commit:

```bash
git show -s --format='%H%n%an <%ae>%n%cn <%ce>%n%B' HEAD
```

The output must not contain:

- Claude
- Codex
- Cursor
- Co-authored-by
- generated by
- automated by

## Commit scope

One coherent engineering unit per commit.

Examples:

```text
docs: establish restoration inventory
fix(data): restore manifest path resolution
test(model): add speaker-count regression coverage
refactor(train): centralize stage configuration loading
repro: pin compatible training dependencies
docs(results): reconcile historical experiment claims
```

## Commit body

For larger changes, include:

- problem
- solution
- validation

## No history rewrite by default

Do not use filter-branch, filter-repo, interactive mass rewriting or equivalent history rewriting merely to change old authors.

Historical contributor attribution is separate from future commit identity.

## Push gate

Before push:

1. tests appropriate to the change pass
2. working tree contains only intended changes
3. issue ledger is updated
4. relevant docs are updated
5. commit identity is correct
6. no disallowed attribution exists
